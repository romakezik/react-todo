# ToDo App

Учебный проект: менеджер задач на React + Vite.

## Возможности
- добавление, редактирование (двойной клик), удаление, пометка выполненных задач
- фильтры: все / активные / выполненные
- регистрация, вход, приватные маршруты, удаление профиля
- данные хранятся в localStorage браузера

## Запуск
npm install
npm run dev

## Ограничения
Авторизация эмулируется в учебных целях: пользователи и пароли
хранятся в localStorage в открытом виде. В реальном приложении
нужен бэкенд с хешированием паролей.
