# ToDo App
https://romakezik-todo.netlify.app/

Учебный проект: менеджер задач на React + TypeScript + Vite.

## Возможности
- добавление, редактирование (двойной клик), удаление, отметка выполненных задач
- фильтры: все / активные / выполненные
- регистрация, вход, приватные маршруты, удаление профиля
- аутентификация и данные — Supabase (PostgreSQL + RLS)

## Стек
- React 19 + TypeScript
- React Router v7
- Supabase (Auth + Postgres + Row Level Security)
- Vite

## Запуск
npm install
npm run dev
